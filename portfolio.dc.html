CASE STUDY · ZERO TO ONE

Create a portfolio with AI

Built this site’s layout and component architecture using a small set of durable principles to guide development with AI agents.
Role
Designer, systems owner, editor
Partners
Claude, Claude Design, Gemini as reviewer
Timeline
About 10 weeks, in 1.5-hour windows, 2026
Scope
Design system, layout, AI workflow

Overview

I’m returning as a Staff designer, and knowing when and how to use AI is now a core part of the craft. So I built my portfolio with agents, as practice and as proof.
My constraint was time: about an hour and a half a day, during my toddler’s nap. Agents handled production so that window went to the parts only I could do: context, judgment, and voice.

Finding a tool that respects small changes

It took four false starts across Claude, Claude Design, and Google Stitch before the workflow held. Stitch regenerated entire pages when I only wanted to change one thing, didn’t follow direction well, and made inline editing painful. I stopped using it.
That set my criteria: a small change stays a small change, and I can edit in place. Claude Design met both.

Deciding what to leave out

I pulled years of work out of an unpublished portfolio, then cut most of it. Work from 2020 and earlier undersold the level I’m applying for, so I led with a few recent projects that show leadership and scope instead.

A loose system that hardened as I built

I didn’t design the system up front. I started with a few strong principles and kept the rest loose, so the system could follow the work instead of blocking it.
Principles first: tokens for color, type, and spacing, plus a handful of rules, like accent never sitting next to primary.
Name it when it repeats: when I described a pattern twice, it got a name, like Feature card, Grid card, meta row, and identity eyebrow. The names gave the agent and I a shared vocabulary.
Rules from real cases: dark-mode contrast, breakpoints, and type hierarchy became rules only after a page broke them.
One source of truth: the UI kit and the live site stay in sync on every change, documented in Foundations.

Working with AI: it suggests, I decide

Gemini reviewed my copy and I critiqued its feedback, keeping only what was accurate to the work and true to my voice. Claude built, and I reverted freely when a direction didn’t hold.
Early on, I gated larger changes behind formal review and approval. Working solo, reviewing as changes landed was faster, so I stopped. With a team, I’d bring the gates back.

Outcome

Principles first, completeness later
The system grew from a few rules into named components and documented standards.
Judgment stayed mine
Every cut, copy decision, and design call was reviewed by me before it shipped.
Shipped in nap-time windows
A published portfolio and a reusable design system, built an hour and a half at a time.
